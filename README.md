DisGame
---

## What does it do?
- Build a console script
- Show as playing a Game

## How to use it?
- Go to [DisGame Demo](https://disgame.cunny.cf/)
- Rebuild and Copy the script
- Install [DiscordPTB](https://ptb.discord.com/) or [Vencord](https://vencord.dev/)
- Login to your account
- Press `CRTL` + `Shift` + `I`
- Paste the script within the console tab and `Enter`
- Press `F7` to Toggle the Game Selection On/Off
- Search and Select a game from the Modal

## How to Add Games
- Go to Discord `Desktop App`
- Press `CRTL` + `Shift` + `I`
- Go to `Application Tab` > `Local Storage` > `https://discord.com` > `RunningGameStore`
- On the bottom part of the window, right click the top part `{,...}`
- Press `Copy Object`
- Visit [DisGame Json Cleaner](https://disgame.cunny.cf/json-cleaner/)
- Paste the Copied RunningGameStore
- Copy the Result
- Create a [New Issue](https://github.com/cunny-cf/DisGame/issues/new) and set the tag to `Add Game`
- Set a Title and Paste the Copied Result in the Description either as a _file_ or _raw text_
